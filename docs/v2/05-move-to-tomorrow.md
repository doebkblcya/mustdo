# 一键移到明天

## 目标

用户可以从正常待办列表快速把一条未完成任务安排到明天。

## 展示规则

- 在今天和后续列表的未完成待办上提供“移到明天”快捷操作。
- 明天列表中的事项保持现有操作集合。
- 已完成事项保持现有完成态操作集合。
- 入口放在待办卡片的快捷操作区或更多菜单中。

## 操作行为

点击后立即执行：

1. 将 `due_date` 更新为明天；
2. 保留任务内容；
3. 保留原 `due_time`；
4. 保留置顶状态；
5. 清除提醒状态；
6. 从当前列表移除并进入明天列表；
7. 显示“已移到明天”的短暂反馈。

操作反馈提供撤销入口。撤销时恢复原日期，并保持提醒关闭。

## API

```http
POST /api/todos/{todo_id}/move-to-tomorrow
```

响应返回更新后的完整待办：

```json
{
  "id": 12,
  "content": "提交周报",
  "due_date": "2026-08-25",
  "due_time": "17:00",
  "status": "pending",
  "pinned": false,
  "reminder": null
}
```

## 前端更新

- 使用乐观更新让任务即时离开当前列表。
- 同步更新本地 `today`、`tomorrow` 和 `upcoming` 分组。
- 重新计算日历圆点。
- 清除今天或明天的 AI 整理缓存。
- 请求失败时按任务 ID 回滚到原列表和原位置。

## 验收标准

- 今天和后续的未完成待办可以一键移到明天。
- 内容、具体时间和置顶状态得到保留。
- 原提醒被清除。
- 页面即时更新，无需显示整页加载状态。
- 操作可以在短暂反馈期内撤销。
- 接口只能修改当前用户拥有的待办。
