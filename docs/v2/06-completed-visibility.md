# 完成项显示控制

## 目标

用户可以按需要显示或隐藏已完成任务，在保留完成状态的同时控制当前列表的信息密度。

## 交互规则

- 已完成事项默认显示。
- 列表操作区提供“隐藏已完成／显示已完成”切换按钮。
- 按钮文案始终表示点击后的动作。
- 切换对今天、明天和后续列表统一生效。
- 切换只改变展示结果，待办状态保持不变。

## 状态保存

显示偏好保存在小程序本地：

```text
mustdo_show_completed = true | false
```

页面启动时读取该值；首次使用默认设为 `true`。

## 列表行为

- 显示完成项时沿用现有排序：置顶优先、未完成优先、完成项随后。
- 隐藏完成项时，仅从渲染列表过滤 `status=done` 的事项。
- `todos.groups` 保留完整数据，重新显示时可以直接恢复。
- 完成一项后，根据当前显示偏好决定它继续显示或退出列表。
- 日历圆点继续只根据未完成事项计算。
- AI 整理只接收当前可见的未完成事项。

## 验收标准

- 初次进入列表时显示完成项。
- 用户可以一键隐藏和重新显示完成项。
- 切换页面和重新打开小程序后保持上次选择。
- 隐藏操作不会删除或修改任务。
- 完成新任务时列表行为符合当前显示偏好。
